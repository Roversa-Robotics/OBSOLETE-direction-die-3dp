# direction-die-3dp - 3D Print & CAD Files

A six sided die with faces matching the Roversa robot directional buttons. This repository contains the CAD design files, export formats, and finishing instructions for the 3D-printed directional die project (featuring **ROVERSA** typography and directional indicators).

---

## Repository Structure

The files in this repository are organized as follows:

├── cad/
│   └── directional-die.f3d       # Native Fusion 360 parametric design archive
├── exports/
│   ├── directional-die.step      # Universal CAD exchange format for solid modeling
│   └── directional-die.stl       # Mesh format ready for slicing and 3D printing
└── README.md                     # Project overview and finishing guide

* **`cad/`**: Contains the original Fusion 360 source archive (`.f3d`) preserving feature history, sketches, and parametric dimensions.
* **`exports/`**: Contains production-ready files including standard `.stl` for 3D printer slicers and high-precision `.step` files for import into other CAD software.

NOTE: each update that changes the f3d file should also update the step and stl files accordingly.

## Finishing Guide: Debossed Text Paint & Wipe Method

To give the debossed letters and icons maximum visual contrast, use the **Acrylic Paint & Wipe** technique detailed below. This method fills the recessed geometry while keeping the top face clean.

### Required Supplies & Links

| Item | Purpose | Link |
| :--- | :--- | :--- |
| **Clear Coat Spray (Matte/Satin)** | Seals layer lines to prevent paint bleeding into micro-gaps. | [Rust-Oleum Painter's Touch 2X Clear Matte](https://www.amazon.com/dp/B002BWOS5I) |
| **Heavy-Body Acrylic Paint** | Thick acrylic paint that fills grooves without bleeding. | [Liquitex Heavy Body Acrylic Paint](https://www.amazon.com/dp/B000KNPLR8) |
| **Detail Paint Brushes** | Fine-tip brushes for pushing paint into small recessed areas. | [Arteza Detail Paint Brushes Set](https://www.amazon.com/dp/B085CD2P7N) |
| **Blue Shop Towels** | Lint-free paper towels for wiping surface paint flat. | [Scott Shop Towels Original Blue](https://www.amazon.com/dp/B00004Z47L) |
| **Isopropyl Alcohol (99% IPA)** | Cleans up paint haze or dried residue from top faces. | [Isopropyl Alcohol 99% on Amazon](https://www.amazon.com/s?k=isopropyl+alcohol+99) |

*Estimated total cost for supplies is approximately **$33 – $51** if purchasing all items new online.*

### Step-by-Step Instructions

1. **Seal the Print:** Apply a light, even coat of clear spray sealer to the printed die and let it dry completely. This seals the layer lines against capillary action.
2. **Fill the Crevices:** Use a fine detail brush to dab heavy-body acrylic paint into the debossed text and icons.
3. **Wipe the Top Surface:** Wrap a blue shop towel tightly around a flat block or ruler, lightly dampen it with water, and glide it smoothly across the top face in one flat motion to remove surface paint without dipping into the debossed text.
4. **Clean & Touch Up:** Use a shop towel lightly dampened with Isopropyl Alcohol (IPA) to clear away any faint paint haze remaining on the top face.
